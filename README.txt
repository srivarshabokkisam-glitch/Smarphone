SMART CALL ASSISTANT — STARTER PROJECT

WHAT IT DOES
- Log incoming, outgoing, or missed calls manually
- Save contact name, phone number, notes, and follow-up date
- Search call history and delete entries
- Generate sample smart replies and copy them
- Stores entries in this browser's localStorage

HOW TO RUN
1. Extract Smart_Call_Assistant.zip.
2. Open the folder.
3. Open index.html in Chrome, Firefox, or Edge.
   If clipboard features are restricted when opened as a file, use VS Code with Live Server.
4. Your data remains in the same browser on the same device.

IMPORTANT LIMITATIONS
This is a front-end prototype, not a real phone dialer. It does not read call logs,
record calls, answer calls automatically, access contacts, or send SMS. Those features
require a native Android app, permissions, and in some cases default-dialer privileges.
Ask for consent before recording or processing calls, and follow local laws and store policies.

PROJECT FILES
index.html — user interface
style.css — responsive design
app.js — demo logic and browser storage
